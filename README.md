# EMBEDDED360

An immersive virtual engineering laboratory for embedded systems, electronics, robotics and IoT. Zero-build static site.

Author: Dr Bansilal Bairwa, School of Electrical and Electronics Engineering, REVA University, Bengaluru.

## Deployment

Static site, no build step. Served directly from the repository root via GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

Entry point: index.html (loads js/app.js as an ES module).
